# Armada I: Premonitions

Clean-room Megadroid Mission Mod conversion of the first *Star Trek: Armada*
Federation mission for Fleet Operations and the STA2 Classic A1 Addon.

The package contains the tested `A1PremonTest` Lua mission and BZN map, its
three objective files, and the A1 compatibility ODF trees used by the add-on.
The diagnostic probe missions, `mmm_loader.dll`, original media, models, and
textures are not included.

Mission conversion and compatibility work: Blade/Apoclaydon.
